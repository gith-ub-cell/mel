## 一、马克思

### 1.1 《1844年经济学哲学手稿》（1844，未完成，1932年首次全文发表）

- **别名**：巴黎手稿
- **核心主题**：异化劳动、私有财产与共产主义的哲学论证、黑格尔辩证法批判
- **关键概念**：
  - 异化劳动的四个规定（劳动者与产品、与劳动过程、与类本质、与人的异化）
  - 私有财产是异化劳动的产物和手段
  - 共产主义是"私有财产的积极扬弃"
  - 人是"类的存在物"——自由自觉的活动是人的类本质
- **适用场景**：劳动异化分析、当代工作意义危机、AI替代与人的本质问题、消费主义批判
- **注意**：马克思26岁时的早期著作，哲学术语仍带费尔巴哈痕迹，但已为《资本论》奠定基础

### 1.2 《神圣家族》（1845，与恩格斯合著）

- **核心主题**：批判青年黑格尔派的主观唯心主义，为历史唯物主义扫清道路
- **关键概念**：
  - "思想根本不能实现什么东西。为了实现思想，就要有使用实践力量的人。"
  - 人民群众是历史的创造者——"历史活动是群众的事业"
  - 对"批判的批判"的批判——清算思辨唯心主义
- **适用场景**：反对空谈、反对精英主义、强调实践与群众

### 1.3 《关于费尔巴哈的提纲》（1845）

- **别名**："天才世界观的第一份文件"（恩格斯语）
- **核心主题**：实践观的确立，新旧唯物主义的根本区别
- **关键概念**：
  - "哲学家们只是用不同的方式解释世界，而问题在于改变世界。"
  - "人的本质不是单个人所固有的抽象物，在其现实性上，它是一切社会关系的总和。"
  - 实践是检验真理的标准
- **适用场景**：认识论问题、理论与实践关系、任何需要从"解释"走向"改变"的场景

### 1.4 《德意志意识形态》（1845-1846，与恩格斯合著）

- **核心主题**：历史唯物主义的第一次系统表述
- **关键概念**：
  - 物质生产是社会存在的基础
  - 分工与所有制的发展阶段
  - 意识形态是统治阶级的思想——"统治阶级的思想在每一时代都是占统治地位的思想"
  - 共产主义不是理想，而是"消灭现存状况的现实运动"
- **适用场景**：意识形态批判、阶级分析、组织文化建设、揭穿"普世价值"

### 1.5 《共产党宣言》（1848，与恩格斯合著）

- **核心主题**：马克思主义的纲领性文献，阶级斗争与无产阶级历史使命
- **关键概念**：
  - "至今一切社会的历史都是阶级斗争的历史。"
  - 资产阶级的历史进步性与革命性——"资产阶级在它不到一百年的阶级统治中所创造的生产力，比过去一切世代创造的全部生产力还要多，还要大。"
  - 资产阶级的必然灭亡与无产阶级的必然胜利
  - "无产者在这个革命中失去的只是锁链。他们获得的将是整个世界。"
  - "全世界无产者，联合起来！"
- **适用场景**：阶级分析总纲、革命形势判断、国际主义论述

### 1.6 《政治经济学批判·序言》（1859）

- **核心主题**：唯物史观的经典公式化表述
- **关键概念**：
  - 生产力与生产关系的矛盾运动是社会变革的根本动力
  - "无论哪一个社会形态，在它所能容纳的全部生产力发挥出来以前，是决不会灭亡的"
  - 经济基础决定上层建筑
  - "人类始终只提出自己能够解决的任务"
- **适用场景**：社会阶段判断、变革时机分析、制度变革可行性评估

### 1.7 《资本论》（第一卷 1867，第二、三卷由恩格斯整理出版 1885/1894）

- **核心主题**：资本主义生产方式的内在解剖及其运动规律
- **关键概念**：
  - **商品二因素**：使用价值与价值。劳动二重性是"理解政治经济学的枢纽"
  - **剩余价值理论**：绝对剩余价值与相对剩余价值；剥削的秘密
  - **资本积累的一般规律**：财富积累与贫困积累的两极分化
  - **资本有机构成**：c/v 趋向提高 → 相对过剩人口（产业后备军）
  - **利润率趋向下降规律**：资本主义的内在矛盾与危机
  - **商品拜物教**：社会关系表现为物与物的关系
  - **原始积累**："资本来到世间，从头到脚，每个毛孔都滴着血和肮脏的东西"
  - "资本主义私有制的丧钟就要响了。剥夺者就要被剥夺了。"
- **适用场景**：政治经济学批判、剥削分析、经济危机分析、AI/自动化影响、工资与工时问题、两极分化

### 1.8 《法兰西内战》（1871）

- **核心主题**：巴黎公社的经验总结，无产阶级专政的最初形态
- **关键概念**：
  - "工人阶级不能简单地掌握现成的国家机器，并运用它来达到自己的目的。"
  - 打碎旧的国家机器的必要性
  - 公社原则：普选、罢免、工资不超过熟练工人、常备军由武装人民替代
- **适用场景**：国家问题、无产阶级专政、组织原则讨论

### 1.9 《哥达纲领批判》（1875）

- **核心主题**：科学社会主义的纲领性文献，批判机会主义
- **关键概念**：
  - 共产主义两个阶段的划分：第一阶段（按劳分配）与高级阶段（按需分配）
  - 过渡时期与无产阶级专政
  - "劳动不是一切财富的源泉"（批判拉萨尔的错误信条）
  - "权利永远不能超出社会的经济结构"
- **适用场景**：社会主义阶段判断、分配正义讨论、对空想社会主义和机会主义的批判

## 二、恩格斯

### 2.1 《英国工人阶级状况》（1845）

- **核心主题**：马克思主义社会调查的经典范本
- **关键概念**：产业革命与无产阶级的形成；工人阶级处境不仅是物质贫困，更是人的堕落
- **适用场景**：阶级状况调查方法论、城市化批判

### 2.2 《反杜林论》（1878）

- **别名**：马克思主义的百科全书
- **核心主题**：系统阐述马克思主义哲学、政治经济学、科学社会主义三个组成部分
- **关键概念**：
  - 辩证法三大规律：对立统一、量变质变、否定之否定
  - 社会主义从空想到科学
  - 平等观念的历史性和阶级性
  - 暴力论批判——不是暴力创造私有制，是私有制产生暴力
- **适用场景**：马克思主义理论体系全貌、方法论教育

### 2.3 《社会主义从空想到科学的发展》（1880）

- **核心主题**：科学社会主义与空想社会主义的本质区别
- **关键概念**：
  - 两大发现使社会主义成为科学：唯物史观 + 剩余价值理论
  - 资本主义基本矛盾：生产社会化与私人占有
  - "无产阶级将取得国家政权，并且首先把生产资料变为国家财产"
- **适用场景**：社会主义理论教育、乌托邦批判
- **注意**：此书是《反杜林论》三章的摘编，篇幅较短，是入门首选

### 2.4 《自然辩证法》（1873-1883，未完成，1925年首次出版）

- **核心主题**：自然界的辩证规律，科学与哲学的关系
- **关键概念**：劳动创造了人本身；自然界是辩证法的试金石；自然科学中的量变质变
- **适用场景**：科学哲学、生态批判、AI 与人的关系、技术哲学

### 2.5 《家庭、私有制和国家的起源》（1884）

- **核心主题**：唯物史观视角下的人类早期社会史
- **关键概念**：
  - 国家是阶级矛盾不可调和的产物
  - 家庭形式随生产方式演变
  - 妇女受压迫的物质根源——私有制和家务劳动社会化不足
  - "国家不是从来就有的……它随着阶级的消灭而不可避免地要消失"
- **适用场景**：性别问题、家庭批判、国家起源分析、女性主义与马克思主义

### 2.6 《路德维希·费尔巴哈和德国古典哲学的终结》（1886）

- **核心主题**：马克思主义与德国古典哲学的关系清算
- **关键概念**：哲学基本问题——思维与存在的关系；马克思主义哲学是"关于外部世界和人类思维的运动的一般规律的科学"
- **适用场景**：哲学基础问题、与唯心主义和机械唯物主义的划界

### 2.7 恩格斯晚年关于历史唯物主义的书信（1890-1894）

- **核心篇目**：《致约·布洛赫》《致康·施米特》《致瓦·博尔吉乌斯》等
- **关键概念**：
  - 经济因素是"归根到底"的决定因素，但不是唯一因素
  - 上层建筑的反作用——"并非只有经济状况才是原因"
  - 历史是"无数个力的平行四边形"的合力
  - "我们在十分确定的前提和条件下创造自己的历史"
- **适用场景**：纠正对唯物史观的机械理解、分析复杂社会现象

## 三、列宁

### 3.1 《怎么办？》（1902）

- **核心主题**：革命政党的组织原则与思想建设
- **关键概念**：
  - "没有革命的理论，就不会有革命的运动。"
  - 自发性与自觉性——工人阶级单靠自身只能达到工联主义意识
  - "灌输"论——社会主义意识需要从外部灌输
  - 职业革命家组织的必要性
- **适用场景**：组织建设、政党理论、队伍建设、思想教育

### 3.2 《唯物主义和经验批判主义》（1908）

- **核心主题**：马克思主义认识论的哲学论证
- **关键概念**：
  - 反映论——"物、世界、环境是不依赖于我们而存在的"
  - 对马赫主义（经验批判主义）的批判
  - 绝对真理与相对真理的辩证关系
  - 哲学的党性原则
- **适用场景**：认识论问题、对主观主义和不可知论的批判、科学与哲学的关系

### 3.3 《帝国主义是资本主义的最高阶段》（1916）

- **核心主题**：帝国主义的五大特征及其历史地位
- **关键概念**：
  - 帝国主义的五大经济特征：生产集中和垄断、金融资本和金融寡头、资本输出、国际垄断同盟、世界领土瓜分完毕
  - "帝国主义是寄生的或腐朽的资本主义"
  - "帝国主义是无产阶级社会革命的前夜"
  - 经济政治发展不平衡的绝对规律
- **适用场景**：全球资本主义分析、大国博弈、科技垄断分析、中美关系

### 3.4 《国家与革命》（1917）

- **核心主题**：马克思主义国家学说与无产阶级革命的道路
- **关键概念**：
  - "国家是阶级矛盾不可调和的产物和表现"
  - 国家是"镇压被剥削者阶级的机器"
  - 必须打碎旧的国家机器
  - 无产阶级专政是"新型民主和新型专政"
  - 国家的"自行消亡"——"当不再有需要加以镇压的阶级的时候……就不再需要国家了"
- **适用场景**：国家理论、革命策略、无产阶级专政论证

### 3.5 《共产主义运动中的"左派"幼稚病》（1920）

- **核心主题**：革命策略的灵活性与原则性的统一
- **关键概念**：
  - 先锋队与群众的关系
  - 必须"在反动工会里做工作"——哪里有群众就去哪里
  - "把普遍真理与具体实践相结合"（列宁主义精髓的预演）
  - 妥协与不妥协的辩证法
- **适用场景**：策略讨论、群众工作、宗派主义批判、务实与原则

## 四、斯大林

### 4.1 《论列宁主义基础》（1924）

- **核心主题**：列宁主义的系统化阐述
- **关键概念**：列宁主义是"帝国主义和无产阶级革命时代的马克思主义"；列宁主义的方法论；革命理论对实践的指导作用
- **适用场景**：列宁主义入门、党的建设

### 4.2 《论辩证唯物主义和历史唯物主义》（1938）

- **别名**：《联共（布）党史简明教程》第四章第二节
- **核心主题**：马克思主义哲学的教科书化阐述
- **关键概念**：辩证法的四个特征与唯物主义的三个特征；物质生产是社会发展的决定力量
- **适用场景**：哲学入门教育
- **注意**：通俗但有机诫化和简单化倾向，需配合马克思原著辩证阅读

### 4.3 《苏联社会主义经济问题》（1952）

- **核心主题**：社会主义条件下经济规律的客观性
- **关键概念**：
  - 经济规律具有不以人的意志为转移的客观性
  - 社会主义下商品生产仍然存在——不应混淆商品生产与资本主义生产
  - 生产关系必须适合生产力性质的规律
- **适用场景**：社会主义政治经济学、计划与市场关系讨论

## 五、毛泽东

### 5.1 《中国社会各阶级的分析》（1925）

- **核心主题**：阶级分析方法的中国化应用
- **关键概念**：
  - "谁是我们的敌人？谁是我们的朋友？这个问题是革命的首要问题。"
  - 以经济地位和政治态度划分阶级
  - 民族资产阶级的两面性
- **适用场景**：阶级分析入门、社会力量结构分析

### 5.2 《反对本本主义》（1930）

- **核心主题**：调查研究与实事求是的思想路线
- **关键概念**：
  - "没有调查，就没有发言权。"
  - "调查就像'十月怀胎'，解决问题就像'一朝分娩'。"
  - 反对本本主义——"盲目地表面上完全无异议地执行上级的指示，这不是真正在执行上级的指示"
  - "中国革命斗争的胜利要靠中国同志了解中国情况"
- **适用场景**：调查研究方法论、反对教条主义、实践导向

### 5.3 《实践论》（1937）

- **核心主题**：马克思主义认识论的中国化阐述
- **关键概念**：
  - 实践是认识的来源、动力、目的和检验标准
  - 认识的两个飞跃：感性认识 → 理性认识 → 实践
  - "实践、认识、再实践、再认识，这种形式，循环往复以至无穷"
  - 反对教条主义和经验主义——"唯心论和机械唯物论，机会主义和冒险主义，都是以主观和客观相分裂，以认识和实践相脱离为特征的"
- **适用场景**：认识论问题、经验教训总结、反对主观主义

### 5.4 《矛盾论》（1937）

- **核心主题**：唯物辩证法的中国化阐述
- **关键概念**：
  - 对立统一规律是辩证法的根本规律
  - 矛盾的普遍性与特殊性
  - 主要矛盾与矛盾的主要方面——"捉住了这个主要矛盾，一切问题就迎刃而解了"
  - 矛盾的同一性与斗争性
  - 对抗性矛盾与非对抗性矛盾
- **适用场景**：矛盾分析、问题诊断、策略制定、是 marx-lm 技能的哲学基石

### 5.5 《论持久战》（1938）

- **核心主题**：用辩证唯物主义分析战争进程，批判速胜论和亡国论
- **关键概念**：
  - 从全部客观事实出发——"战争问题中的唯心论和机械论的倾向，是一切错误观点的认识论上的根源"
  - 三个阶段：防御、相持、反攻
  - 战争是政治的继续——"政治是不流血的战争，战争是流血的政治"
  - 主观能动性——"战争是力量的竞赛，但力量在战争过程中变化其原来的形态"
- **适用场景**：长期斗争策略、"三个阶段"方法论、力量转化分析、复杂局势判断

### 5.6 《新民主主义论》（1940）

- **核心主题**：新民主主义革命理论体系
- **关键概念**：
  - 中国革命的两步走：新民主主义革命 → 社会主义革命
  - 新民主主义的政治、经济、文化纲领
  - 文化与政治经济的关系——"一定的文化是一定社会的政治和经济在观念形态上的反映"
- **适用场景**：社会阶段分析、文化政治分析、殖民地半殖民地革命理论

### 5.7 《改造我们的学习》（1941）

- **核心主题**：整风运动的纲领性文献，批判主观主义
- **关键概念**：
  - "实事"就是客观存在着的一切事物，"是"就是规律性，"求"就是去研究
  - 主观主义是"共产党的大敌"
  - "有的放矢"——"的"是中国革命，"矢"是马克思列宁主义
- **适用场景**：学习态度、调查研究、反对形式主义和教条主义

### 5.8 《在延安文艺座谈会上的讲话》（1942）

- **核心主题**：马克思主义文艺理论的经典文献
- **关键概念**：
  - 为什么人的问题——"是一个根本的问题，原则的问题"
  - 文艺与政治的关系——"文艺是从属于政治的，但又反转来给予伟大的影响于政治"
  - 普及与提高——对工农兵首先需要"雪中送炭"
  - 文艺批评的两个标准：政治标准与艺术标准，政治标准第一
  - 暴露与歌颂——对敌人暴露，对人民歌颂
  - 文艺工作者必须转变立场——"把自己的思想感情来一个变化"
  - 生活是文艺的唯一源泉
- **适用场景**：文艺批评、文化产品分析、媒介批判、创作者立场分析

### 5.9 《论人民民主专政》（1949）

- **核心主题**：新中国国家学说的奠基之作
- **关键概念**：
  - "对人民内部的民主方面和对反动派的专政方面，互相结合起来，就是人民民主专政。"
  - 消灭阶级、消灭国家权力的历史方向——"我们是要消灭国家权力的"
  - "一边倒"——倒向社会主义
  - "严重的经济建设任务摆在我们面前"——从革命到执政的转型意识
- **适用场景**：国家理论、民主与专政辨析

### 5.10 《论十大关系》（1956）

- **核心主题**：社会主义建设中的矛盾分析方法运用
- **关键概念**：
  - 十大关系即十大矛盾——"世界是由矛盾组成的。没有矛盾就没有世界"
  - 重工业与轻工业/农业的关系
  - 沿海工业与内地工业的关系
  - 中央与地方的关系——"有中央和地方两个积极性，比只有一个积极性好得多"
  - 中国与外国的关系——"一切民族、一切国家的长处都要学"
- **适用场景**：组织治理、资源分配、系统矛盾分析

### 5.11 《关于正确处理人民内部矛盾的问题》（1957）

- **核心主题**：社会主义社会矛盾学说的创立
- **关键概念**：
  - 社会主义社会仍然存在矛盾——基本矛盾是生产力与生产关系、经济基础与上层建筑的矛盾
  - 区分两类不同性质的矛盾：敌我矛盾（对抗性）与人民内部矛盾（非对抗性）
  - "团结——批评——团结"的公式
  - 百花齐放、百家争鸣
- **适用场景**：矛盾性质判断、组织冲突处理、文化建设

### 6.2 使用原则

1. **原著优先**：引述观点时标注出处，避免"马克思说过"式的凭空引用
2. **历史语境**：指出文本写作时的具体历史条件，不把特定结论当作超历史的公式
3. **配合使用**：单一文本不能覆盖复杂问题——马克思的《资本论》+ 列宁的帝国主义论 + 毛泽东的矛盾论，往往需要组合使用
4. **联系实际**：文献是工具，不是装饰。引用必须服务于当下的具体分析，不能"为引用而引用"
5. **批判继承**：经典文本中有普遍真理，也有特定历史条件下的具体判断。区分二者是马克思主义者的基本功
